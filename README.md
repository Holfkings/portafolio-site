# Portfolio Site — Holfkings

Personal portfolio website: premium HTML/CSS/JS, responsive, animated. Dark theme design.

**Live site:** https://holfkings.github.io/portafolio-site/

---

## What it is

A personal portfolio site for a freelance web developer. Showcases services, projects, tech stack, and contact.

Built as a single-page site with smooth scrolling, hover animations, and a dark premium aesthetic.

---

## Stack

- HTML5 semantic
- CSS3 (custom properties, flex, grid, animations, media queries)
- Vanilla JavaScript (smooth scroll, mobile menu, scroll animations)
- Google Fonts: Inter, Space Grotesk

---

## Structure

```text
portafolio-site/
├── index.html          # Main page
├── css/
│   └── styles.css      # Complete styles
└── js/
    └── main.js         # Interactions
```

---

## Local development

No build step. Open `index.html` directly or serve locally:

```bash
cd portafolio-site
python -m http.server 8000
# Open http://localhost:8000
```
