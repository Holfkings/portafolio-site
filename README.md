## ✨ What It Is

A personal portfolio website for a freelance web developer. Single-page site with smooth scrolling, hover animations, and a dark premium aesthetic — built to showcase services, projects, tech stack, and contact.

**No frameworks. No build step. Just clean, hand-crafted code.**

---

## 🎯 Features

| Feature | Detail |
|---------|--------|
| **Hero section** | Bold headline, tagline, CTA buttons |
| **Services** | What I offer as a freelance developer |
| **Projects** | Showcase of work with links |
| **Tech stack** | Technologies I work with |
| **Contact** | Get in touch section |
| **Responsive** | Mobile, tablet, desktop |
| **Dark theme** | Premium dark aesthetic |
| **Smooth scroll** | Navigation between sections |
| **Hover animations** | Interactive feedback on elements |

## 📁 Project Structure

```text

├── css/

    └── main.js         # Interactions — vanilla JavaScript
```

## ⚡ Quick Start

No installation. No dependencies. Open and go.

```bash
# Clone the repo
git clone https://github.com/Holfkings/portafolio-site.git
cd portafolio-site

# Option A — open directly
# Double-click index.html or open in browser

# Option B — local server
python -m http.server 8000
# Open http://localhost:8000
```
